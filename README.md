In order to run the application, the .env file needs to be setup correctly. The 'DB_HOST' field needs to be a string with the name of the database host (it will most likely be localhost), the 'DB_USER' field needs to be a string with the username (most likely root), the 'DB_PASSWORD' field needs to be a string with the password of your MySQL account, and finally the 'DB_NAME' field needs to be the name of the database you wish to connect to. See the .env file for an example. 

Another important part of running the application is making sure all of the neccessary python libraries have been downloaded. The easiest way to do this is to  create a virtual environment by running the command: "python -m venv venv", and once the virtual environment is created and active, run the command: "pip install requirements.txt" which will download all of the libaries in the requirements.txt file.
